A full-featured PHP engine for creating dynamic web interfaces using Yii2

This package allows you to create Laravel [Livewire](https://livewire.laravel.com/) style reactive components for Yii2 without building the front end *(Webpack/Vite)* and without writing manual AJAX actions.

## Installation

```bash
composer require hydina/defina-moon
```

## Get information

Open console on your Yii project and insert:
```bash
yii hydina
```

## Get started

Create your first component:
```bash
yii hydina/livewire --component=Counter
```

The result will be:
```php
<?php
namespace frontend\livewire\widgets;
use Hydina\DefinaMoon\App\Component;

class Counter extends Component
{

    public function run(): string
    {
        return $this->view('counter');
    }

}
```

Open your component using the following path:
`\frontend\livewire\widgets\views\counter.php`

Add this code:
```php
<?php
/** @var int $count */
use yii\helpers\Html;
?>
<div>
    <h3>counter: <?= Html::encode($count) ?></h3>
    <div>
        <button class="btn btn-light" wire:click="decrement">-</button>
        <button class="btn btn-light" wire:click="increment">+</button>    
    </div>
</div>
```

Update your widget:
```php
<?php
namespace frontend\livewire\widgets;
use Hydina\DefinaMoon\App\Component;

class Counter extends Component
{
    public int $count = 0;
    public string $search = '';

    public function increment(): void
    {
        $this->count++;
    }
    public function decrement(): void
    {
        $this->count--;
    }

    public function run(): string
    {
        return $this->view('counter');
    }
}
```

Update your Layout:
`\frontend\views\layouts\main.php`:
```php
<?php
declare(strict_types=1);
/** @var yii\web\View $this */
/** @var string $content */
use Hydina\DefinaMoon\Assets\LivewireAsset; // <---
LivewireAsset::register($this); // <---
use common\widgets\Alert;
use yii\bootstrap5\Breadcrumbs;
use yii\helpers\Html;

$this->render('_head');
?>
<?php $this->beginPage() ?>
<!DOCTYPE html>
...
```

Add in your controller
`\frontend\controllers\SiteController.php`
```php
public function actionCounter(): string
{
    return $this->render('counter');
}
```
and in view
`\frontend\views\site\counter.php`:
```php
<?php
use frontend\livewire\widgets\Counter;
$this->title = 'Counter';
?>
<div>
    <h1>Test Livewire in Yii2</h1>
    <?=Counter::widget();?>
</div>
```
You are not limited in where you place models, views, and controllers; likewise, a widget component can have any name—for convenience, the script creates a file and a component with the same name.

## Updating the Model's Status

Add to Controller:
```php
use common\models\User;
...

public function actionUser(): string
{
    $model = User::findOne(1);
    return $this->render('user', ['model' => $model]);
}
```

Generated by the command:
```bash
yii hydina/livewire -c=UserCard -m=User -n="common\models"
```
where `-c`, `-m`, `-n` is aliases:
```
'c' => 'component',
'm' => 'modelClass',
'n' => 'ns',
't' => 'targetNamespace'
```

Update your widget class `/frontend/livewire/widgets/UserCard.php`:
```php
<?php
namespace frontend\livewire\widgets;

use common\models\User;
use Hydina\DefinaMoon\App\Component;

class UserCard extends Component
{
    public ?User $model = null;

    public function toggleStatus(): void // <---
    {
        if ($this->model) {
            $this->model->status = $this->model->status === 10 ? 9 : 10;
            $this->model->save(false);
        }
    }

    public function run(): string
    {
        return $this->view('user-card');
    }
}
```
Update a component `frontend/livewire/widgets/views/user-card.php`
```php
<?php
/** @var \common\models\User|null $model */
use yii\helpers\Html;
?>
<div>
    <?php if ($model) { ?>
		<?=Html::tag('p', 'Username: '.Html::encode($model->username));?>
		<?=Html::tag('p', 'Status: '.Html::encode($model->status));?>
		<?=Html::button('Change Status', [
			'wire:click' => 'toggleStatus',
			'class' => 'btn btn-primary'
		]);?>
    <?php } ?>
</div>
```
Call on the page `frontend/views/site/user.php`
```php
<?php
use frontend\livewire\widgets\UserCard;
/** @var \common\models\User|null $model */
?>
<?=UserCard::widget(['model' => $model]);?>
```

### Search Widget with Model

started command:
```bash
yii hydina/livewire --c=PostSearch -m=Post
```
`frontend/livewire/widgets/PostSearch.php`
```php
<?php
namespace frontend\livewire\widgets;

use common\models\Post;
use Hydina\DefinaMoon\App\Component;

class PostSearch extends Component
{
    public string $search = '';

    /**
     * @return Post[]
     */
    public function posts(): array
    {
        return $this->computed('posts', function () {
            return Post::find()
                ->filterWhere(['like', 'title', trim($this->search)])
                ->orderBy(['id' => SORT_DESC])
                ->all();
        });
    }

    public function run(): string
    {
        return $this->view('post-search');
    }
}
```

Update a component
`frontend/livewire/widgets/views/post-search.php`
```php
<?php
/** @var \frontend\livewire\widgets\PostSearch $component */
/** @var string $search */
use yii\helpers\Html;
?>
<div>
    <?=Html::input(
        'text', 
        null, 
        Html::encode($search), 
        [
            'wire:model.live' => 'search',
            'placeholder' => 'Search...',
            'class' => 'form-control'
        ]
    );?>
    <p class="text-secondary">
        Posts found: <?=count($component->posts());?>
    </p>

    <?php foreach ($component->posts() as $post): ?>
        <div class="border border-secondary-subtle rounded p-4 mb-3">
            <h3><?=Html::encode($post->title);?></h3>
            <p><?=Html::encode($post->body);?></p>
        </div>
    <?php endforeach; ?>

    <?php if (empty($component->posts())): ?>
        <p>No results were found for the search term «<b><?=Html::encode($search);?></b>».</p>
    <?php endif; ?>
</div>
```
Call on the page `frontend/views/site/posts.php`
```php
<?php
use frontend\livewire\widgets\PostSearch;
?>
<div>
<?=PostSearch::widget();?>
</div>
```
**Note:** A 250-millisecond delay is built into the search after text is entered. The search does not run immediately or after every character entered, but only after the user stops typing in the input field.


# Bonus

You can used link navigation:
```html
<a href="/link" wire:navigate>Your link</a>
```

⚡This creates an “SPA”-effect for [HDA](https://htmx.org/essays/hypermedia-driven-applications/), allowing users to follow links without reloading the entire page.

> ⚠️ This package already includes [Alpine.js](https://alpinejs.dev/), so you can write your own custom client-side scripts.
